# EX5 Music

แอป Android ขนาดเล็กสำหรับจอกลางรถ Geely EX5 (Flyme Auto) หรือจอ Android อื่น

- **Apple Music**: ปุ่มใหญ่สำหรับเปิดแอป Apple Music ที่ติดตั้งไว้ และเปิดลิงก์ `music.apple.com/…`
  ที่พิมพ์ วาง หรือแชร์มาจากแอปอื่น ลิงก์จะเปิดในแอป Apple Music (ถ้ามี) หรือในเบราว์เซอร์
- **เล่นไฟล์ Lossless**: FLAC / WAV / AIFF / ALAC (.m4a) และไฟล์ทั่วไปจาก USB หรือหน่วยความจำของจอ
  มีปุ่มเลือกโฟลเดอร์ เลือกไฟล์ และสแกนทั้งหมด (MediaStore) รองรับปุ่มบนพวงมาลัย (MediaSession)
  และเล่นต่อได้ตอนสลับไปหน้าจออื่น บรรทัดสีแดงจะแสดง codec, kHz และ bit ของเพลงที่เล่นอยู่

แอปนี้ไม่ได้สตรีมหรือถอดรหัสเพลงของ Apple Music เอง ถ้าจะฟัง Lossless จาก Apple Music
ต้องเปิดในแอป Apple Music ทางการ (Settings → Audio Quality → Lossless Audio)
แอปนี้ใช้ตัวถอดรหัสของระบบ ไฟล์ ALAC ต้องใช้ Android ที่มีตัวถอดรหัส ALAC (โดยทั่วไปคือ Android 10 ขึ้นไป)

## Build

Workflow `.github/workflows/ex5-music.yml` จะรันเทสต์และบิลด์ APK ทุกครั้งที่ไฟล์ในโฟลเดอร์นี้เปลี่ยน
หรือสั่ง **Run workflow** เอง ดาวน์โหลดได้จาก artifact `ex5-music-apk`

APK เซ็นด้วย debug key ที่สร้างใหม่ทุกครั้งที่บิลด์ ถ้าจะลงเวอร์ชันใหม่ทับ ต้องถอนเวอร์ชันเก่าออกก่อน

## ติดตั้งบนจอรถ

ผู้ผลิตไม่ได้รับรองการลง APK บนจอ Flyme Auto จอบางเวอร์ชันอาจบล็อกไว้
และการเปิดโหมดผู้พัฒนาอาจกระทบการรับประกัน ควรถามศูนย์บริการก่อน
ถ้าจอรถลงไม่ได้ แอปนี้ก็ใช้บนมือถือ Android ได้เหมือนกัน
